# 灌区转供配额仓

归并分水闸计量、灌区配额、临时调剂及权利户取水资料，建一套同时服务两类岗位的数仓：站务查下一次许可（`permit_check`），水权岗对结算（`district_settlement`、期结凭据与户级差额）。`data/facts.json` 为本地合成记录，含表计更换、共享闸次和迟到归户。

## 口径与能力

- **放水认定**：按表计口径版本（revision）切段。换表以登记的新表底数另起基线；同段内读数反转视为未登记归零，记录异常并按归零重启认定，不产生负水量。闸次单只作核对，认定量以表计为准，归户分量不得超过认定量。
- **预约**：取水请求注明服务地块与取水时段；登记时按同期余量校验（配额 + 有效转入剩余 − 有效转出剩余 − 已确认耗用 − 在册预约 − 共享渠段未归户占用），不给同期请求重复许诺。
- **共享闸次**：分量未确认时，未归户部分按最保守口径全额占用每个候选区的余量——不预先均摊，任何权利户都不能把这段量当成可用。补报分量或更正换表口径后，可核耗用转成归户事实，预约结余随之释放、可再预约。
- **结算**：实际耗用按闸次开始日判定当时的配额与调剂有效性；预约量与实际耗用有出入时释放剩余或登记超量；调剂到期不把当时合法耗用退回水权池。配额不足时列出已发生耗用与待处理预约，已确认放水不抹掉。
- **日结 / 期结**：日结先核对完整渠段，未齐渠段可查（`close_day`、`incomplete_sections`）。期结签出配额凭据后凭据保留不改；追溯撤销、迟到计量、分量更正一律走权利户差额，校验按户进行——灌区合计相同不能盖住户间错误（`validate_period`）。

## 运行

需要 Python 3.11 或更新版本，无第三方依赖。运行 `python3 -m unittest discover -s tests` 检查计量修订、预约结算与期结差额。

## 结构

- `warehouse/model.py` — 数据模型与时间口径（灌区本地墙钟，结算期为自然月）
- `warehouse/meter.py` — 表计台账：换表底数、读数反转、窗口放水量认定
- `warehouse/ledger.py` — 主账：配额、调剂、预约、归户、日结期结、凭据与差额
- `warehouse/loader.py` — 载入 `data/facts.json` 建账（历史资料缺地块/时段会留警告）
